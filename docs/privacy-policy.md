# Privacy policy

The standalone public privacy policy is published from the `xmikuskad/pokeandscan-privacy-policy` repository on GitHub Pages:

- English: <https://xmikuskad.github.io/pokeandscan-privacy-policy/en/>
- Slovak: <https://xmikuskad.github.io/pokeandscan-privacy-policy/sk/>

The Settings privacy action opens the page matching the app's saved language (`en` or `sk`). Keep the URL mapping in `PrivacyPolicy.kt` aligned with these URLs if the GitHub Pages canonical address changes.

The standalone repository is the source of truth for the public pages. Update both language pages there when data practices change, keep the effective date current, and verify both URLs and their shared assets after publishing. Its README contains maintainer instructions; it is not part of either policy page.
