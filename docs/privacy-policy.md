# Privacy policy

The standalone public privacy policy is published from the `xmikuskad/pokeandscan-privacy-policy` repository on GitHub Pages:

- English: <https://xmikuskad.github.io/pokeandscan-privacy-policy/en/>
- Slovak: <https://xmikuskad.github.io/pokeandscan-privacy-policy/sk/>

The Settings privacy action opens the page matching the app's saved language (`en` or `sk`). Keep the URL mapping in `PrivacyPolicy.kt` aligned with this page if the GitHub Pages canonical address changes. The public site source and update instructions are in the standalone repository; its README is maintainer guidance and is not part of either policy page.
